# Wear 界面设计依据

## 官方资料与参考项目

- [Wear Material 3 Expressive](https://developer.android.com/design/ui/wear/guides/get-started/apply)：色调层级、圆角形状、空间运动与圆屏适配。
- [TimeText](https://developer.android.com/design/ui/wear/guides/components/time-text)：圆屏弧形时间、方屏水平时间，列表滚动时淡出。
- [Wear 列表](https://developer.android.com/design/ui/wear/guides/components/lists)：左右边距为屏幕宽度的 5.2%，标题与内容间距 12dp。
- [Wear 颜色](https://developer.android.com/design/ui/wear/guides/styles/color)：纯黑背景、强调色与容器色、Wear 专用颜色角色及内容对比度。
- [官方曲线组件](https://developer.android.com/reference/kotlin/androidx/wear/compose/foundation/package-summary)：`CurvedLayout`、`curvedBox`、`basicCurvedText` 与 `CurvedModifier.background` 支持曲线布局、圆角底板和文字。
- [Wear 导航](https://developer.android.com/design/ui/wear/guides/m2-5/behaviors-and-patterns/navigation)：非关闭导航使用垂直轴，向右滑动用于返回。
- [Android 动画指南](https://developer.android.com/develop/ui/compose/animation/quick-guide)：页面进入与退出可以配置方向一致的滑动过渡。
- [官方 TimeText 源码](https://github.com/androidx/androidx/blob/androidx-main/wear/compose/compose-material3/src/main/java/androidx/wear/compose/material3/TimeText.kt)：最大弧度 70°、arcMedium 字号、系统 12/24 小时格式与时间广播。
- [官方 CurvedText 源码](https://github.com/androidx/androidx/blob/androidx-main/wear/compose/compose-material3/src/main/java/androidx/wear/compose/material3/CurvedText.kt)：时间底色使用背景色的 85% 不透明度。
- [官方 MotionScheme 源码](https://github.com/androidx/androidx/blob/androidx-main/wear/compose/compose-material3/src/main/java/androidx/wear/compose/material3/MotionScheme.kt)：Expressive 的 slowSpatialSpec 使用 stiffness=200、dampingRatio=0.8，适合位置变化。
- [官方 ScrollAway 源码](https://github.com/androidx/androidx/blob/androidx-main/wear/compose/compose-material3/src/main/java/androidx/wear/compose/material3/ScrollAway.kt)：新页面和闲置状态显示时间，滚动时移出、淡出。

参考 [WearFiles](https://github.com/NickWoluff/WearFiles) 的 `app/src/main/java/com/nickwoluff/wearfiles/WatchUi.kt`：它由 `AppScaffold` 绘制统一时间层，`ScreenScaffold` 提供列表滚动状态，时间不参与列表内容测量。

## 当前实现

首页与历史页使用 Java/XML，以独立的 `FloatingTimeView` 承载 Compose 时间覆盖层。圆屏直接调用官方 `TimeText`，方屏调用官方水平 `Text`，复用 `TimeTextDefaults` 的时间源、格式、字体与底色。覆盖层不接收触摸、不参与内容测量，也不重复出现在 TalkBack 焦点中。官方时间源使用应用 Context 注册时间广播，避免布局重建时 Activity 自动清理与协程注销之间的竞态。

设置页直接使用 AndroidX Wear Compose Material 3 的 `AppScaffold`、`ScreenScaffold`、`TimeText`、`ListHeader`、`Button`、`RadioButton` 和 `CircularProgressIndicator`，主题采用 `MotionScheme.expressive()`。检查更新与前往 Release 的按钮均为官方 `Button`；圆屏列表使用 `TransformingLazyColumn` 与官方 `SurfaceTransformation`。官方 `TimeText` 源码仅绘制弧线，因此方屏改用水平 `Text`，复用 `TimeTextDefaults` 的时间源、时间格式、字体与背景色。设置页时间通过官方滚动状态自动浮现与隐藏。历史页在纵向滚动时移出时间，停止滚动 2 秒后淡入。首页只翻动按钮层，算式和结果位置固定。方屏圆点指示器高度为 4dp，仅留 6dp 按钮底部空间。

“屏幕布局”参考 WearFiles，折叠为显示当前布局的官方 `Button` 入口，点击打开官方 `AlertDialog`，使用[官方 RadioButton](https://github.com/androidx/androidx/blob/androidx-main/wear/compose/compose-material3/src/main/java/androidx/wear/compose/material3/RadioButton.kt)提供方屏、圆屏单选项，选择后立即保存并关闭弹窗。重复选择当前布局也关闭弹窗；弹窗显示时下滑不退出设置页面。首次启动记录系统报告的屏幕形状；后续按用户选择保存到 `SharedPreferences`。通过 Activity 的局部 Configuration 覆盖 round 标记，统一选择 XML 资源、列表、时间和悬浮提示的形状。切换时重建页面，首页返回时同步更新，保留当前算式、结果、2nd 状态与按钮页码。

设置与主题入口统一使用官方 `androidx.compose.material:material-icons-extended:1.7.8`（与 WearFiles 相同版本），由 Wear Material 3 `Icon` 显示，尺寸使用 `ButtonDefaults.IconSize`：检查更新为带圆环箭头和时钟指针的 `Update`（与 Credex 一致），自动检查为 `Autorenew`，主题和强调色为 `Palette`，屏幕布局为 `Watch`，调色板风格为 `Style`，前往 Release 为自动镜像的 `OpenInNew`。检查中使用官方 `CircularProgressIndicator`。移除原手绘更新矢量资源。

## 版权信息

设置列表最下方使用官方 `Text` 居中显示版权，字体和颜色使用主题的 `bodySmall` 与 `onSurfaceVariant`。2026 年显示 `© 2026 Nick Woluff. All Rights Reserved.`，之后根据设备当前年份自动显示 `© 2026-当前年份 Nick Woluff. All Rights Reserved.`。

## 自动检查更新

参考 Credex 的更新检查与启动逻辑：默认开启，通过 `SharedPreferences` 持久保存开关，每次打开首页只检查一次。设置使用官方 Wear `SwitchButton`，开启时说明“启动时检查”，关闭时说明“仅手动检查”。自动检查只在发现新版本时显示官方 `AlertDialog`，提供前往 Release 的操作；最新版、网络失败或不合法版本不弹提示。手动检查保留原来的检查状态与悬浮提示。首页通过 `ViewModel` 保留请求和结果，切换布局、主题或旋转导致的页面重建不会重复检查；退出首页后取消请求，关闭开关后未完成请求的结果不再提示。

## 手势与页面过渡

历史页在最新记录所在的列表底部继续上滑可退出；设置页在列表顶部继续下滑可退出。手势先区分横向与纵向，退出拖动超过 48dp 才生效；向列表内部滚动和历史行的横向滑动继续交由原控件处理。退出动画与页面进入方向相反。

官方没有专门命名的“设置上拉／历史下拉”动画。当前选择垂直滑动，并把上述 Expressive slow spatial 弹簧采样为原生 `pathInterpolator`，窗口过渡时长为 650ms。设置从屏幕下方进入，历史从上方进入；返回沿相反方向退出，底层首页保持静止。API 34 及以上使用 `overrideActivityTransition`，旧版本使用 `overridePendingTransition`。

窗口过渡是依据官方运动参数实现的 View 适配；悬浮时间、设置与主题页采用官方 Compose 组件。Wear Compose 1.7.1 的 AAR 要求 compileSdk 37、minSdk 25，因此编译 SDK 调整为 37.0，最低版本调整为 Android 7.1（API 25），targetSdk 保持 36。

## 主题设置

设置页提供官方 `Button` 入口，主题页只显示“强调色”和“调色板风格”两个折叠选项，并显示当前值。参考嗷呜文件的 `WatchUi.kt` 与 `AppSettings.kt`：点击入口打开官方 `AlertDialog`，其中使用官方 `RadioButton`；选中后立即保存并收起。强调色依次提供经典、紫、蓝、青、绿、橙、粉，经典为默认配置，已保存的强调色继续生效。调色板支持 Tonal Spot、Vibrant、Expressive、Neutral、Monochrome、Fidelity。C 与退格按钮在普通主题下使用强调色容器角色。经典保留原 XML 的手配按钮色（数字 `#2D2F33`、运算 `#4B586B`、清除 `#824C51`、三角函数 `#254A48`、对数 `#41405B`）及 2nd 选中背景；页码指示器选中颜色为 `#B0B0B0`、未选中颜色为 `#555555`，翻页插值也保持灰色。其他强调色的指示器继续使用主题颜色；调色板风格仍用于生成设置等 Compose 页面的主题。

使用现有 Material 1.13.0 的官方 Material Color Utilities（`Hct` 与对应 `Scheme`）生成暗色调色板，映射到 Wear `ColorScheme`，保持纯黑背景。该库将这些算法标注为内部 API，适配集中在 `AppAppearance`，未来升级 Material 依赖时需复核。Compose 页面实时响应选择；返回首页或历史页时重建并为 XML 控件应用颜色角色，首页保留计算状态、按钮页码与 2nd 状态。圆屏列表使用官方变形效果，方屏列表支持表冠滚动。

## 弧形悬浮提示

当前 `WatchFloatingNotice.kt` 直接复制自 WearFiles 的同名文件，除包名外代码完全一致。`ArcToastView` 仅承担 Java 调用、Compose 承载、替换提示和触摸穿透，不重新实现提示的排版或动画。WearFiles 实现使用官方 `CurvedLayout` / `curvedBox` / `curvedText` 绘制圆屏底板与文字，方屏使用水平 `Box` / `Text`。曲线文字采用 `WarpOffset.None`；长文按字素边界截取连续子串、移动锚点，并通过裁剪与渐变遮罩淡出边缘。动画、无障碍超时、liveRegion 播报和 ON_STOP 清理均沿用原实现。

覆盖层不拦截触摸，重复提示会替换上一条，结束或离开设置页后移除。
